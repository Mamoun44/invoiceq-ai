# DeliveryAddressDetails

Deliver-to address (IBG-15), not the buyer postal address. Conditional — see Oman field overrides.

## Fields

### country

Required: No
Type: string
Description: Country of the delivery address.

### city

Required: No
Type: string
Description: City of the delivery address.

### street

Required: No
Type: string
Description: Street of the delivery address.

### area

Required: No
Type: string
Description: Area or district of the delivery address.

### postalCode

Required: No
Type: string
Description: Postal code of the delivery address.

### pobox

Required: No
Type: string
Description: PO box of the delivery address.

### buildingNumber

Required: No
Type: string
Description: Building number of the delivery address.

### provinceCode

Required: No
Type: string
Description: Country subentity of the delivery address. When delivery country is AE/ARE: emirate code (AUH, DXB, SHJ, UAQ, FUJ, AJM, RAK). For non-UAE delivery: foreign region/state code.
